# apLists 1.0.7

The free community edition provides subscriber lists, consent records, double opt-in, segmentation, suppression, and CSV import and export. It is GPLv2 or later and does not require a license key.

This release improves error handling for subscriber changes, confirmations and unsubscribes, and prevents incomplete CSV exports when a database read fails. It also blocks subscriptions when the suppression list cannot be checked.

## Installation

Download the packaged `artistpro-lists-1.0.7-community.zip` release asset. Back up your site and database. If an older community or paid apLists edition is active, deactivate it before activating this edition. The new package uses the `artistpro-lists` folder; older and paid editions use `aplists`, so WordPress may install it separately. Verify your lists and subscribers after the change. See the [installation guide](https://artistprowp.com/docs/aplists-getting-started/).
